# Sales Prediction Using Machine Learning Techniques

A machine learning project that predicts sales using historical data and Random Forest Regression.

## Project Overview

Sales prediction helps businesses estimate future sales and make better decisions using historical data.

This project applies machine learning techniques to analyze sales data and predict sales values.

## Objectives

- Analyze historical sales data
- Prepare and preprocess the dataset
- Train a machine learning model
- Predict sales values
- Evaluate model performance
- Identify important features affecting sales

## Machine Learning Model

The project uses:

- Random Forest Regression
- Train-Test Split
- Feature Importance Analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)````````````
- Root Mean Squared Error (RMSE)
- R² Score

The project achieved an R² score of approximately **0.7925**.

```bash

```

### 2. Install required libraries

```bash
pip install -r requirements.txt
```

### 3. Run the Python program

```bash
python sales_prediction.py
```

## Results

The Random Forest Regression model provides sales predictions based on the available historical data.

Feature importance analysis is also used to understand which variables contribute most to the prediction.

## Conclusion

This project demonstrates how machine learning can be used for sales prediction. Random Forest Regression provides a useful approach for learning patterns from historical sales data and generating predictions.
